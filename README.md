# Alok Awasthi — Portfolio

Personal portfolio at https://portfolio-awasthi.netlify.app/

Built with React 18 and Vite. Deployed on Netlify (settings in `netlify.toml`). The contact form uses Netlify Forms.

## Editing content

All text (experience, projects, skills, education, links) lives in `src/data.js`.
The downloadable resume is `public/Alok-Awasthi-Resume.pdf`.

## Local development

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs to dist/
```
